# Contributing to VelvetAura

First off, thank you for your interest in the VelvetAura theme!

## ⚠️ Important Notice Regarding Code Modifications

This theme is licensed under **CC BY-ND 4.0 (Attribution-NoDerivatives)**. This means:
- You are free to use this theme on any website (personal or commercial).
- **You are strictly prohibited from modifying, altering, or creating derivative works of the source code.**

Because of this strict license, **we do not accept Pull Requests that modify the theme's code, structure, or assets.**

## How You Can Contribute

Even though code modifications are not allowed, we still value your feedback! You can help us improve VelvetAura by:

1. **Reporting Bugs:** If you find a visual glitch, broken layout, or a JavaScript error, please open an [Issue](https://github.com/rj-nexus/velvet-aura/issues) with a detailed description and screenshots.
2. **Suggesting Features:** Have an idea for a new header style or widget? Open an Issue and let us know!
3. **Translating:** If you want to help translate the theme's strings (`__('...')`), please contact us via GitHub.
4. **Spreading the Word:** Share the theme with others who are using RJ CMS.

## Reporting a Bug

When reporting a bug, please include:
- Your RJ CMS version.
- Your PHP version.
- Steps to reproduce the issue.
- Screenshots or screen recordings (if applicable).

Thank you for respecting the license and helping us keep VelvetAura beautiful!
