# AI Center & Dashboard Chat

RJ CMS integrates AI to help you write, translate, and manage your site.

## Dashboard AI Chat
The Dashboard is a full-screen AI Assistant (similar to ChatGPT). It uses a free, keyless API by default so it works out of the box. It can answer questions about your site stats (posts, pages, users) and guide you on how to use the CMS.

## AI Center Tabs
Go to **AI Center** in the sidebar to access:
1.  **Overview:** View total requests, tokens used, and costs.
2.  **Models:** Select which AI models (from OpenRouter) to use for different tasks (Default, SEO, Translation, Builder).
3.  **Prompts:** Customize the system prompts used for SEO, translation, and builder AI.
4.  **Usage:** View a detailed log of every AI request, including the model used, tokens consumed, and the user who made it.
5.  **Tools:**
    *   *Content Generator:* Generate a full blog post from a topic.
    *   *Bulk Translate:* Translate all posts/pages into another language.
    *   *SEO Auditor:* Scan the site for posts missing SEO meta data.

## AI Settings
To use advanced AI features (like OpenRouter), go to **Settings > AI** and enter your API key. If no key is provided, the system falls back to the free API where possible.
