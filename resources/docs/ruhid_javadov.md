## The RJ CMS Project
Ruhid Javadov created RJ CMS with the vision of building a modern, self-hosted, open-source alternative to WordPress. The project has evolved into **RJ Nexus**, an open-source platform that emphasizes:
- Clean, modern architecture.
- A powerful visual page builder (RJBuilder).
- AI integration (OpenRouter and free AI services).
- A robust plugin and theme ecosystem.
- A fully open marketplace (in contrast to the legacy RJ CMS 5.1).
