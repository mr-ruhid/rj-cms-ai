# Categories & Tags Management

This document explains how to organize your content using taxonomies.

## How to create a Category
1. Go to **Posts > Categories**.
2. Fill in the **Name**, **Slug**, and an optional **Description**.
3. You can select a **Parent Category** to create a hierarchy (e.g., News > Tech).
4. Click **Add New Category**.

## How to create a Tag
1. Go to **Posts > Tags**.
2. Fill in the **Name** and **Slug**.
3. Click **Add New Tag**.

## Multilingual Support
Both Categories and Tags support multiple languages. When creating or editing a taxonomy, you can switch between language tabs to provide translated names and descriptions.

## Assigning to Posts
When editing a post, you can check the boxes for the desired Categories and type in Tags in the right sidebar.
