# System Tools

RJ CMS includes several advanced tools to maintain and monitor your site.

## Site Health
Go to **Tools > Health** to run 30+ automated checks on your server, database, and security. It also provides an **AI Analysis** button to generate a prioritized action plan for fixing any issues.

## Backup
Go to **Tools > Backup** to create manual or scheduled backups. It zips your database and uploaded files.
*   **Local Backups:** Stored on the server (default limit: 5).
*   **Download Backups:** Generated specifically for you to download to your computer (default limit: 2).
*   You can restore a backup directly from the dashboard.

## Logs
Go to **Tools > Logs** to read your Laravel `laravel.log` files directly in the browser. Filter by severity (Error, Warning, Info) and expand stack traces.

## Import / Export
*   **Export:** Download your content (posts, pages, menus, settings) in JSON, WordPress WXR (XML), or CSV format.
*   **Import:** Upload a JSON, WXR, or CSV file to migrate content into RJ CMS.

## Diagnostics
Go to **Tools > Diagnostics** to view detailed system information (PHP version, server limits, database size, file paths). Useful for debugging or support.
